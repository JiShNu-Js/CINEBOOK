# 🎬 CineBook – Movie Ticket Booking System

CineBook is a web-based movie ticket booking application developed
as part of our Internet Programming group assignment.

It allows users to browse movies, select theatres and showtimes,
choose seats, and book tickets online.

## ✨ Features

- User registration and login
- Browse available movies
- Dynamic theatre selection
- Select show dates and showtimes
- Interactive seat selection
- Automatic ticket price calculation
- Booking confirmation and printable tickets
- Admin dashboard for managing movies and theatres

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- Git and GitHub

## 🚀 Installation and Setup

### 1. Clone the repository

    git clone https://github.com/JiShNu-Js/CINEBOOK.git
    cd CINEBOOK

### 2. Install dependencies

    npm install

### 3. Configure environment variables

Copy `.env.example` to `.env` and configure your database credentials.

### 4. Set up MySQL

Import `database.sql` into your MySQL database.

### 5. Start the application

    npm start

Open http://localhost:3000 in your browser.
